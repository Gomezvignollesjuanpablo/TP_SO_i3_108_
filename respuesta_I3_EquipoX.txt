e- El principal problema técnico que tuvimos fue el Conflicto de Merge (Merge Conflict) en los archivos compartidos (datos.txt y beta.txt). Este conflicto ocurre porque Git es una herramienta que rastrea cambios línea por línea. Cuando GAMMA subió el archivo a GitHub, y luego ALFA (o GAMMA al querer corregirlo) modificaron las mismas líneas del mismo archivo localmente, Git no sabe automáticamente con cuál versión quedarse ni cómo combinarlas sin pisar el trabajo del otro. Al intentar hacer el git pull o git merge, Git detuvo el proceso automáticamente, marcó los archivos con etiquetas de conflicto (<<<<<<< HEAD, =======, >>>>>>>) y nos obligó a abrir los archivos con un editor de texto (nano) para borrar manualmente las marcas y ordenar el texto de forma que quedara la información de ambos integrantes.
